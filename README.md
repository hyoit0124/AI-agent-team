# AI 에이전트 본부 (AI-agent-team)

ChatGPT(수석실장)와 Claude(4개 담당)가 함께 일하는 본부 저장소입니다.
업무 지시, 보고, 역할 지침을 이곳에서 관리하고, 각 프로젝트의 코드는 프로젝트별 저장소에서 관리합니다.

## 조직도

| 직책 | 담당 | 핵심 역할 | 주요 산출물 |
|---|---|---|---|
| 대표 | Hyo | 최종 의사결정, 우선순위 승인 | 승인 / 반려 |
| 수석실장 | ChatGPT | 프로젝트 기획, 업무 분배, 결과 검토, 종합 보고 | 업무 지시서, 검토 의견, 주간 보고 |
| 마케팅담당 | Claude | 타깃·채널·콘텐츠 전략, 카피 | 마케팅 플랜, 카피, 콘텐츠 캘린더 |
| 전략기획담당 | Claude | 시장·경쟁 분석, 사업 구조, 수치 시뮬레이션 | 기획서, 시나리오 표, 리스크 분석 |
| 디자인담당 | Claude | 브랜드·UI·비주얼 방향 | 디자인 가이드, 화면 시안 |
| 기술개발담당 | Claude | 앱·웹 구현, 자동화 | PRD, 코드, 프로토타입 |

각 직책의 상세 지침은 [`roles/`](roles/) 폴더에 있습니다.

## 업무 흐름 (GitHub 연결 기준)

| 단계 | 담당 | 내용 | 상태 |
|---|---|---|---|
| 1. 지시 | 수석실장 | GitHub 작업 이슈와 연결된 지시서 작성 | 지시 |
| 2. 수락 | Claude Code | 실행 시 GitHub 지시서를 읽고 이슈에 수락 보고 | 지시 → 진행중 |
| 3. 작업·보고 | Claude 담당 | 프로젝트별 브랜치에서 작업 → PR·검증 근거 보고 | 진행중 → 검토요청 |
| 4. 검토 | 수석실장 | 저장소의 결과물을 읽고 검토 의견 작성 | 검토요청 |
| 5. 승인 | Hyo | 최종 확인 | 완료 |

수정이 필요하면 수석실장이 이슈와 지시서에 수정 요청을 남기고 담당자가 후속 커밋을 제출합니다.

상세 절차는 [GitHub 협업 규약](docs/GITHUB-COLLABORATION.md), 에이전트 시작 지침은 [AGENTS.md](AGENTS.md)와 [CLAUDE.md](CLAUDE.md)를 따릅니다. GitHub 연결만으로 Claude Code가 자동 실행되거나 새 지시를 상시 감시하지는 않습니다. 최초 실행은 대표가 시작합니다.

## 폴더 구조

```
AI-agent-team/
├── README.md        # 이 문서 — 조직도·운영 규칙
├── projects.md      # 진행 중인 프로젝트와 저장소 목록
├── roles/           # 직책별 역할 지침
├── templates/       # 지시서·보고서 양식
├── tasks/           # 업무 지시서 (업무 1건 = 파일 1개)
└── reports/         # 주간·프로젝트 종합 보고
```

## 운영 규칙

1. 업무 1건 = 지시서 파일 1개. 파일명: `YYYY-MM-DD_담당_업무명.md` (예: `2026-11-03_마케팅_클립랩-출시-카피.md`)
2. 지시서 필수 항목: 목표 / 배경 / 산출물 형식 / 마감 / 완료 기준
3. 보고는 결론 먼저, 근거 2~3개, 수치 포함, 다음 실행 제안으로 마무리
4. 코드·디자인 결과물은 해당 프로젝트 저장소에 저장하고, 지시서에 경로를 남김
5. API 키·비밀번호는 어떤 파일에도 올리지 않음

## 호출 문구

- **ChatGPT에게**: "수석실장, [프로젝트명]의 다음 업무를 지시서 양식으로 작성해줘"
- **Claude Code에게**: "본부 CLAUDE.md를 읽고 지정된 작업 이슈를 확인해 [담당명]으로 수락·처리해줘"
- **ChatGPT에게 검토 요청**: "수석실장, AI-agent-team의 tasks/[파일명] 결과물을 검토해줘"
