# 테일러메이드 라운딩 어플

매장 VM 시행도를 체크하는 웹앱입니다. 매주 월요일 VMD가 주간 VM 매뉴얼을 공지하면, 매장 매니저·직원이 앱에서 장표를 보고 매장 사진을 찍어 금요일까지 올립니다. 관리자는 같은 앱에서 업로드 현황을 보고 검수·포상·사진 저장을 합니다.

> 현재는 **시범 버전**입니다. 매장 상태와 다른 매장 사진은 예시 데이터이고, 올린 사진은 그 기기 화면에서만 유지됩니다(새로고침 시 초기화). 실제 운영을 위해서는 클라우드 저장소 연결이 필요합니다(아래 "다음 단계").

## 주요 기능

| 구분 | 화면 | 내용 |
|---|---|---|
| 매장 | 홈 | 이번 주 공지, 마감(금요일 23:59), 주간 매뉴얼 장표 넘겨 보기·크게 보기 |
| 매장 | 업로드 | 장표별 촬영 항목(필수 5 + 선택 1), 기준 장표 보며 촬영, 제출 |
| 매장 | 내 매장 | 이번 달 스탬프판(4칸), 포상 이력, 제출 기록 |
| 관리자 | 현황 | 대리점용(52곳)·백화점용(48곳) 탭, 업로드율, 상태별 필터, 매장별 검수(적합/보완, 베스트 VM) |
| 관리자 | 공지 | 주차·구분·마감 입력, 매뉴얼 파일, 촬영 항목 설정, 대리점용 → 백화점용 복사 |
| 관리자 | 포상 | 스탬프 4/4 매장 후보, 사은품 추가 제공 / 회사 상품권 선정 |
| 관리자 | 사진 저장 | 주차별 ZIP 저장(`11월3주차_대리점/매장명/01_프로모션POP.jpg`), 월 1회 저장 후 삭제 |

## 운영 기준

- 공지: 대리점용 / 백화점용 2종, 매주 월요일 발행
  - 대리점용: 대리점 41 + 직영 9 + 청주에버세이브·한성몰남양주 = 52곳
  - 백화점용: 백화점·아울렛 47 + IFC서울 = 48곳
- 마감: 같은 주 금요일 23:59, 목요일 오전 미제출 매장 리마인드
- 계정: 매장당 2개(매니저·직원), 둘 중 누가 올려도 매장 제출 1건
- 포상: 한 달 공지를 모두 금요일까지 업로드한 매장 중 관리자 선정 → 사은품 추가 제공 또는 회사 상품권
- 사진 보관: 관리자가 월 1회 PC에 저장 후 삭제

## 설치 (홈 화면에 추가)

- 아이폰: **사파리**로 링크 열기 → 공유 → 홈 화면에 추가
- 갤럭시: **크롬**으로 링크 열기 → 메뉴 → 홈 화면에 추가(설치)
- 카카오톡에서 링크를 누르면 카톡 내부 브라우저로 열려 설치가 안 됩니다. 오른쪽 위 메뉴에서 "다른 브라우저로 열기"를 눌러 주세요.

## 파일 구성

```
index.html            앱 전체(화면·로직)
manifest.webmanifest  홈 화면 설치 정보(이름, 아이콘)
sw.js                 오프라인 캐시
icons/                앱 아이콘
slides/               주간 매뉴얼 장표 이미지 (A = 대리점용, D = 백화점용, 01~10)
```

주간 매뉴얼을 바꿀 때는 `slides/` 의 `A01.jpg`~`A10.jpg`, `D01.jpg`~`D10.jpg` 를 새 장표로 교체합니다.
